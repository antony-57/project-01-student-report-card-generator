# Student Report Card Generator

A beginner Python project that collects a student's marks for five subjects, validates the input, calculates the total and average, assigns a grade, and generates a simple report card.

## Features

* Accepts student ID and name
* Collects marks for five subjects
* Validates marks to ensure they are between 0 and 100
* Calculates total marks
* Calculates the average
* Assigns a grade based on the average
* Displays a formatted student report card

## Concepts Practiced

* Variables
* Dictionaries
* Lists
* User input
* Type conversion
* `for` loops
* `while` loops
* `if / elif / else`
* Dictionary iteration with `.items()`
* Basic arithmetic
* Input validation
* Formatted output
